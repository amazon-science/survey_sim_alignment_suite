# Output

This directory is not included in the repository. All files are reproducible:

## Personas
Generated by `scripts/generate_personas.py`. Expected files:
- `socsci210_personas.json`
- `rotten_tomatoes_personas.json`
- `ecommerce_personas.json`

## Inference results
Generated by `scripts/run_inference.py`. Naming: `{source}_{benchmark}_inference.json`

## Evaluation results
Generated by `scripts/run_inference.py --eval_only`. Naming:
- `{source}_{benchmark}_results.csv` — survey-level averages
- `{source}_{benchmark}_results_per_question.csv` — per-question scores

## Baselines
Generated by `scripts/compute_baselines.py`:
- `baselines/{benchmark}_{method}_per_question.json` — per-question baseline scores
- `baselines/significance_summary.json` — significance tests (all conditions vs best)

## Reproduction

```bash
# Generate personas (requires AWS Bedrock access)
for src in socsci210 rotten_tomatoes ecommerce; do
    python scripts/generate_personas.py --data data/sample/${src}_users.json --dataset $src --model claude4.5 --workers 8
done

# Run simulations (requires AWS Bedrock Batch access)
for src in socsci210 rotten_tomatoes ecommerce; do
    for bench in gss opinionqa_w34 opinionqa_w50 opinionqa_w92; do
        python scripts/run_inference.py --data data/benchmarks/${bench}.json --personas output/${src}_personas.json --dataset $src --model claude4.5 --batch --s3_bucket <YOUR_BUCKET> --role_arn <YOUR_ROLE>
    done
done

# Evaluate
for src in socsci210 rotten_tomatoes ecommerce; do
    for bench in gss opinionqa_w34 opinionqa_w50 opinionqa_w92; do
        python scripts/run_inference.py --data data/benchmarks/${bench}.json --personas output/${src}_personas.json --dataset $src --eval_only
    done
done

# Baselines + significance
python scripts/compute_baselines.py
```
